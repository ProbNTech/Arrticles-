## 4. FAQ schema suggestions
These questions are not covered by a dedicated section in the body. Each answer uses only information established in the article.

1. **Can aluminum French doors be used as interior doors?** Yes. Cost guides note that because standard aluminum doesn't insulate well, it is often used for interior doors or for exterior doors in moderate climates.
2. **Should I choose an inswing or outswing aluminum French door?** Inswing doors need clear floor space inside the room, while outswing doors open onto the patio and save interior space. The swing is set when the door is ordered, so measure both areas first.
3. **Can I install an aluminum French door myself?** It's not a beginner project. The doors are heavy and must be installed square and level, and any new or widened opening is structural work that calls for a licensed contractor and a permit check with your local building department.
4. **Why does my aluminum door get condensation on the frame?** Basic aluminum frames conduct cold, so the inside surface can drop below room temperature. A thermally broken frame stays closer to room temperature, which helps limit condensation.
